# 道吾拾

将本文件夹内的全部文件上传到 GitHub 仓库的网页发布目录，保持 index.html、assets 和 site.webmanifest 的相对位置。

GitHub Pages 从哪个目录发布，就将这些文件放到哪个目录。打开网站时使用 HTTPS 地址。

包含学生与教师登录、班级管理、题库及试题、任务与批改、成绩、错题本、成长和知识储备。题库支持改名、文字按题号拆分、题目截图及 JSON 图文导入。

发布后的账号、班级、题库和成绩继续读取页面中已配置的云端服务。本文档随网站文件一起上传即可。


## 2026-11-12 更新

成绩支持精简Excel导出；讲评清单支持Word及PDF/打印，含原题号、选择题选项和做错/失分学生名单；复核题目列表显示得分或对错。

详细修改记录位于 `changes/`。每次维护请按 `AGENTS.md` 新建修改记录。


试卷分析现按实际题目分值、正确率/得分率统计，先列重点题号后按序分析；主观题支持新建及导入后补图。详细记录见 changes。
